Projet M1 TechWeb

Application web développée dans le cadre du M1, avec un backend en FastAPI, une base de données PostgreSQL, et un frontend en React avec Tailwind CSS.

Structure du projet

backend/ : Contient le code FastAPI et la configuration PostgreSQL.

frontend/ : Contient le code React et Tailwind CSS.

.gitignore : Liste des fichiers/dossiers à ignorer.

README.md : Documentation du projet.
